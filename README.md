## What is this about?

Crates is a mod that adds fishing crates to Minecraft to make fishing more interesting!

It is very simple, some biomes have exclusive biome-specific crates containing unique loot related to that biome! Which then allows certain loot to be renewable and easily obtainable.
Data-driven!

## You can add your own crates with a simple data pack and resource pack! Just follow the guide over on the GitHub wiki here. Templates will be provided.

You can get the mod here: [Modrinth Page](https://modrinth.com/mod/svcrates)
